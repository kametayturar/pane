# Instrument – the look of the Meridian screens and the Instrument kit

Interfaces for AI that feel like precision instruments: you can read them, trust them and see where every number
came from. Paper and ink, one signal colour, editorial type, measured motion. Where most AI UI is glossy and vague,
Instrument is exact and calm – a field notebook crossed with an oscilloscope.

Use it when you extend a Meridian screen or add a piece to the "Instrument" group. The general rules in
[build.md](build.md) still apply (one file, `<style href>`, tokens, dark mode, reduced motion, keyboard, a11y, 360–1200px).

## 1. Principles

1. **Show the evidence.** Every generated claim, number or action can show its source, its confidence and the step that
   produced it. Provenance is a first-class visual element, not a tooltip afterthought.
2. **Uncertainty is visible.** Confidence is drawn – as dither density, a tolerance band, a ± readout – never hidden.
3. **Measured, not decorated.** Rules, ticks, scales and crop marks organise the page. Ornament must carry information.
4. **One signal.** A single signal colour marks what is live, chosen or needs attention. Everything else is ink on paper.
5. **Motion explains state.** Things trace in, scan, settle. Nothing bounces for fun. Every animation answers "what changed?".
6. **The agent is a colleague in the room.** Agents have presence (a cursor, a trace, a voice in the margin), not just a
   spinner in a box.

## 2. Tokens

> **Two looks.** Shipped pieces default to the **Classic** look (white sheet on `#fafafa`, ink `#0a0a0a`, signal `#0060e2`;
> dark `#1c1c1e` on `#0c0c0d`, signal `#4d8dff`). Choosing the **Instrument** style (`html[data-style="instrument"]`,
> generated by `scripts/build-styles.py`) restores the paper/ink/orange values below. Build with the token names; never
> hard-code these colours.

Each piece owns a class prefix `.xx` and declares these on its root (copy exactly, rename the prefix):

```css
.xx {
  --xx-paper: #f4f2ec;           /* warm paper – page/stage */
  --xx-sheet: #fbfaf6;           /* card / sheet surface */
  --xx-ink: #141413;             /* true ink */
  --xx-signal: #ff4d00;          /* the one signal colour (international orange) */
  --xx-signal-soft: color-mix(in oklab, var(--xx-signal) 12%, transparent);
  --xx-t1: color-mix(in oklab, var(--xx-ink) 92%, transparent);
  --xx-t2: color-mix(in oklab, var(--xx-ink) 64%, transparent);
  --xx-t3: color-mix(in oklab, var(--xx-ink) 44%, transparent);
  --xx-t4: color-mix(in oklab, var(--xx-ink) 22%, transparent);
  --xx-rule: color-mix(in oklab, var(--xx-ink) 14%, transparent);      /* hairlines */
  --xx-rule-2: color-mix(in oklab, var(--xx-ink) 7%, transparent);     /* faint grid */
  --xx-ok: #1f8a4c; --xx-warn: #b7791f; --xx-bad: #c4321a;            /* used sparingly, as text/ticks */
  --xx-serif: "Instrument Serif", "Iowan Old Style", Georgia, serif;
  --xx-sans: Inter, ui-sans-serif, system-ui, sans-serif;
  --xx-mono: "Geist Mono", "JetBrains Mono", ui-monospace, Menlo, monospace;
  --xx-ease: cubic-bezier(.2, .8, .2, 1);        /* measured: decisive start, exact stop */
  --xx-ease-trace: cubic-bezier(.65, 0, .35, 1); /* for lines drawing in */
  font: 13px/20px var(--xx-sans); color: var(--xx-t1);
}
:is(.dark, [data-theme="dark"]) .xx {
  --xx-paper: #0e0e0d; --xx-sheet: #161614; --xx-ink: #f2efe6; --xx-signal: #ff6a26;
}
```

- **Radius:** 2px on chips and inputs, 4px on cards, 0 on rules. Instrument is crisp – no pill shapes except status dots.
- **Elevation:** no soft drop shadows. Separation comes from hairlines (`0 0 0 1px var(--xx-rule)`) and paper vs sheet.
  The one exception: a floating panel may use `0 1px 0 var(--xx-rule), 0 12px 24px -16px rgb(0 0 0 / .25)`.
- **Signal use:** at most one or two signal marks per view (the live dot, the selected tick, the primary action outline).

## 3. Type

- **Display:** Instrument Serif (Google Font, regular + italic), 28–64px, tracking -0.01em, often with one *italic* word.
- **Body/UI:** Inter 13–15px.
- **Labels and readouts:** mono 10.5–11.5px, UPPERCASE, letter-spacing .08em, colour t3 – used for section labels,
  axis ticks, units, IDs, timestamps ("RUN 0412 · 14:02:11 UTC").
- **Numbers:** mono, tabular. Units smaller and t3 (`412 ms`, `$0.0041`, `±3.1%`).

## 4. Signature details (use several in every piece)

- **Crop marks:** small L-shaped corner marks (8px, 1px, t4) just outside a card's corners instead of a border-radius look.
- **Rulers and ticks:** a top or left edge scale with minor/major ticks and mono labels; the "now" or selected position is
  a signal tick.
- **Readout row:** a strip of key/value readouts separated by hairlines: `TOKENS 41.2k │ COST $0.07 │ LATENCY 812 ms`.
- **Specimen labels:** figure captions like `FIG. 2 — Retrieval scores, top 8` in mono under visuals.
- **Dither as data:** ordered (Bayer) dither where density encodes a value (confidence, load, coverage). Ink dots on paper;
  signal dots only for the live/selected item.
- **Registration grid:** an optional faint 8px dot or line grid on stages (rule-2), fading at the edges.
- **Margin notes:** the agent's commentary appears as small italic serif notes in the margin, joined to the text by a hairline.

## 5. Motion vocabulary

All durations divide by `var(--xx-speed, 1)` where a piece is a studio piece. Respect reduced motion (show the settled frame).

- **Trace:** lines and outlines draw in with `stroke-dashoffset` (500–900ms, `--xx-ease-trace`).
- **Scan:** new content is revealed by a 1px signal line sweeping top-to-bottom (or left-to-right) with content unmasked
  behind it (`clip-path: inset(...)`, 420–700ms), the line fading out at the end.
- **Settle:** numbers count to their value then make one tiny overshoot-and-return (≤2%) on a spring; ticks slide to position.
- **Pulse:** live things have a 1.6s ring pulse on a 6px signal dot – only one per view.
- **Typewriter for agents:** agent-written text appears at a steady pace with a block caret, not word-blur.
- **No:** bouncy springs, parallax, glows, gradients-as-decoration, blur-in (that's the Classic style).

## 6. Layout

- 12-column grid, generous outer margins, content blocks aligned to the grid with visible rules between regions.
- Section heads: mono label + serif title + one-line sans description, left aligned.
- Density: information-rich but airy – 24–32px between groups, 8–12px within.

## 7. Content voice

Plain, specific, numerate. Labels are nouns ("Sources", "Confidence", "Run log"). Invented companies, people and models
only (models: Nova, Atlas, Sage, Quill; companies: Harbor & Finch, Meridian Labs, Northwind Clinics…). No brand logos.
