Result

Audited landing.html with Lighthouse 12 (mobile preset, headless Chrome, served locally on :7001/:7002, 3 runs each) and fixed everything it flagged plus the obvious things it cannot see. Fixed page is landing.after.html (full file below). Scores (median of 3), before -> after: Performance 81 -> 100, Accessibility 27 -> 100, SEO 80 -> 100, Best practices 92 -> 100. FCP 3.0 s -> 0.6 s, LCP 3.7 s -> 0.6 s, TBT 0 -> 0 (the 30M-iteration busy loop only costs ~30 ms here, but it blocks the main thread for that long on every load and far longer on a slow phone). Headless Chrome: load event 2,143 ms -> 513 ms, script time 28 ms -> 0. Top issues found and fixed Performance: (1) render-blocking font stylesheet requesting 2 families x 9 weights with display=block (invisible text until fonts arrive) -> one family, 3 weights, display=swap, loaded non-blocking with the print-media swap trick plus a noscript fallback and preconnects. This was the biggest FCP/LCP win: just adding swap and fewer weights still left FCP at 3.3 s; making the stylesheet non-blocking took it to 0.6 s. (2) jQuery + moment loaded from a CDN, blocking the parser; moment was never used and jQuery was only used for one innerHTML -> both removed, testimonials are now plain HTML (no 1.5 s timer, no layout shift, crawlable). (3) A 30M-iteration empty busy loop in a script tag -> deleted. Accessibility (27 -> 100): missing lang, missing doctype (quirks mode), no <main> landmark; the fake heading <div class="h1"> and h3s directly under the h1 -> real p eyebrow + h2s; the "Get started" CTA was a div with onclick (not focusable, no link semantics) -> real <a href>; cookie "OK" span -> real <button>; emoji hidden from screen readers with aria-hidden; contrast fixed (#999 on white -> #374151; #666 on #111 -> #e5e7eb; white-on-cyan button -> white button with dark purple text; gradient end darkened from #06b6d4 to #0e7490 so white text passes); visible focus outlines. SEO (80 -> 100): added <title>, meta description, meta viewport, lang. Also made the layout responsive (flex-wrap on cards, clamp() heading size, min-height instead of height:100vh). What I did not change / caveats: the old robots.txt failure in my first run was an artifact of my local server returning HTML for every path, so I made the server 404 unknown paths. Lighthouse's lab numbers use simulated mobile throttling and vary +-5 points between runs, so the 3 runs for each version are in the steps. CLS rose from 0.001 to 0.005 because the web font now swaps in after first paint (still far below the 0.1 threshold). Fonts still come from Google; self-hosting a subset would remove that third-party request entirely. The page's /signup target doesn't exist in the fixture.
