Signup flow tested by driving a real Google Chrome (dedicated --user-data-dir in the scratch folder, not the user's profile) through the chrome-cdp skill's CLI, against the fixture on http://127.0.0.1:7131/#signup. Invalid email (dana@clinic, valid name and password): submit is rejected, "Enter a valid work email" shows under the email field, name and password errors stay empty, the result area stays empty. Valid data (dana@clinic.example, 4–10 therapists): the error clears and a role=status banner reads "Account created for dana@clinic.example. Check your inbox." The resource-timing list (cdp net) is empty after the submit, i.e. the "success" never touches a server – it is purely client-side. What the skill's tooling taught me: cdp click runs element.click() through eval, which does NOT focus inputs, so my first attempt (click + type) typed into nothing and all three validation errors appeared (step 3 shows it). Real focus needed clickxy at element-centre coordinates (from getBoundingClientRect) and then type, which is the flow the skill's Coordinates section describes. Environment swap: the skill expects Chrome's DevToolsActivePort file, which Chrome only writes when remote debugging is enabled from chrome://inspect (or port 0). I launched Chrome with --remote-debugging-port=7132 (my assigned range) and wrote the two-line DevToolsActivePort file in the dedicated profile myself from /json/version, then pointed CDP_PORT_FILE at it. No "Allow debugging" modal appeared. Chrome ran headed but off-screen (window position 2000,0).

fillxy.sh (helper around the skill's eval/clickxy/type)
#!/bin/bash
# fillxy.sh <target> <selector> <text>: real mouse click at element centre (clickxy), then type
T=$1; SEL=$2; TXT=$3
XY=$(/tmp/claude-501/lab2/chrome-cdp/cdp.sh eval $T class="s">"(()=>{const r=document.querySelector('$SEL').getBoundingClientRect();return Math.round(r.x+r.width/2)+' '+Math.round(r.y+r.height/2)})()")
echo class="s">"\$ cdp eval (centre of $SEL) -> $XY"
/tmp/claude-501/lab2/chrome-cdp/runlog.sh clickxy $T $XY
/tmp/claude-501/lab2/chrome-cdp/runlog.sh type $T class="s">"$TXT"
